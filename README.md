# Brawl Stars v36 — Season 7

Fan-made private-server project based on the open-source BrawlStars-v36 project.

## Current target
- Protocol/server base: v36.218
- Season: 7
- Featured brawler: Buzz
- No Telegram bot
- No admin panel

## Run

```bash
pip install -r requirements.txt
python Main.py
```

Server port: `9339`.

The project is independent and is not an official Supercell server.
